# 额度哨兵 · 使用手册

> 版本 1.4.0 · Android 8.0+（推荐 Android 13 及以上，小米 / HyperOS 机型已做专门适配）

## 一、这是什么

额度哨兵是一个**只在本机运行**的个人小工具，把你自己在 Claude、ChatGPT、Gemini 上的网页账号连起来，然后：

- **定时保活**：按你设定的计划，在额度窗口重置时自动发一条很短的“Hi”，把 5 小时（可调）的额度周期续上；
- **额度看板**：首页用环形进度显示三家账号的剩余额度、估算剩余条数、还有多久重置；
- **后台常驻**：前台服务 + 开机自启 + 精确闹钟兜底，App 划掉/锁屏后仍继续工作（需要你按第 4 节授权，安卓系统才允许）；
- **历史记录**：每次发送、刷新、异常都记录在首页时间线里。

> ⚠️ 三家服务**没有**给个人账号的公开 API。本 App 用的是它们网页版前端自己的内部接口，
> 需要你从自己的浏览器里复制登录 Cookie。这属于非官方用法：接口可能随时失效，账号也可能因
> 自动化行为收到风控提示。请只在你自己的账号上、以很低的频率（默认 4.5 小时一次）使用，
> 不要用于批量注册、刷量或对外提供服务。
>
> 所有 Cookie / Token 只保存在本机 App 私有目录，不上传任何服务器；本 App 不包含任何统计 SDK。

## 二、安装

APK 文件：`额度哨兵/QuotaSentry-1.0.0.apk`（在手机的 `Download/DSH-Go/额度哨兵/` 里）。

1. 用文件管理器点开 APK，允许“安装未知应用”后安装；
2. 首次打开按提示授予**通知权限**（常驻通知是安卓对前台服务的硬性要求）；
3. 如果系统提示“此应用可能会损害你的设备”，选择“仍然安装”（侧载应用都会这样提示）。

## 三、连接账号（首页 → 右上角设置 → 账号连接）

### 方式 A：粘贴 Cookie（推荐，最稳）

在电脑或手机浏览器里登录对应服务后，用开发者工具复制 Cookie：

1. 电脑浏览器登录 <https://claude.ai> / <https://chatgpt.com> / <https://gemini.google.com>；
2. 按 `F12` 打开开发者工具 → `Network`（网络）→ 刷新页面 → 点第一个 `document` 请求；
3. 在 `Request Headers`（请求头）里找到 `Cookie:`，**整段复制**（很长，正常）；
   或者用 `Application` → `Cookies` → 对应域名，逐条拼成 `a=1; b=2` 格式；
4. 回到 App，点对应服务的「连接」→ 粘贴 → 「测试连接」。

各服务**必需的** Cookie：

| 服务 | 必需字段 | 说明 |
|---|---|---|
| Claude | `sessionKey`（`sk-ant-sid01-...`） | 可能同时需要 `cf_clearance`，整段 Cookie 一起粘贴最保险 |
| ChatGPT | `__Secure-next-auth.session-token` | 可带 `cf_clearance`；App 会自动用它换 access token |
| Gemini | `__Secure-1PSID` | 建议同时带上 `__Secure-1PSIDTS`、`__Secure-3PSID` |

> Cookie 等价于登录态，**不要发给任何人**、不要截图发群里。失效后在浏览器重新登录、重新复制即可。

### 方式 B：Chrome 授权登录（Claude / ChatGPT）

不再使用应用内浏览器，点「Chrome 授权登录」会直接跳到系统 Chrome：

- **Claude**：在 Chrome 里登录并允许授权 → 页面会显示一段授权码 → **复制它**，切回额度哨兵；
  App 回到前台会自动读取剪贴板完成兑换（也可以点面板里的「已复制授权码？点此读取」）。
  授权码很短命，看到后尽快返回。
- **ChatGPT**：在 Chrome 里登录并授权 → 浏览器跳到本地回调页显示「授权成功」→ App 自动收下 token，无需复制。

成功后面板会显示「已连接」和计划名，额度改走官方 OAuth 接口（Claude 还能看到 7 天窗口）。

> ⚠️ OAuth token **只能查额度**。三家都没有「允许第三方 App 以网页身份发消息」的授权，
> 所以保活发送仍需要网页 Cookie：请按方式 A 再粘贴一次对应服务的 Cookie。
>
> Gemini 没有可用的个人 OAuth 额度接口，只能用方式 A 粘贴 Cookie。

> 注意：Android 不允许任何 App 读取 Chrome 的 Cookie（浏览器沙箱），所以「Chrome 登录后自动带回网页登录态」
> 在系统层面就做不到；能自动带回来的只有 OAuth token。

### 代理（国内网络基本必填）

设置 → 网络：

- 打开「代理」，填你本机代理软件的地址与端口（例如 `127.0.0.1:7890`，HTTP 或 SOCKS5）；
- 带用户名密码的代理也支持；
- 手机上没有代理软件时，三家服务很可能连不上，App 会给出「网络不通，请检查代理」的提示。

### 多账号

同一个服务可以连接多个账号（例如两个 Claude）：设置 → 账号连接 → 对应服务下方「添加 Claude 账号」，
新账号默认显示为「Claude 2 / Claude · Pro / 邮箱」。首页每个账号一张额度卡；计划仍按服务配置一条，
到点会对该服务下**所有已连接账号**逐个发送。删除账号只在同服务有多个账号时出现；最后一个账号请用「断开」清空凭据。

## 四、允许后台常驻（关键步骤，Android 12+ 必做）

设置 → 后台保活，把下面四项都处理成绿色：

1. **前台服务**：打开「后台常驻」总开关，通知栏会出现一条常驻通知（这是系统要求，不能隐藏）；
2. **电池优化**：点「去设置」→ 允许后台运行 / 选择「不限制」；
3. **精确闹钟**：点「去设置」→ 允许“闹钟和提醒”（Android 14+ 默认关闭）；
4. **通知权限**：必须允许，否则前台服务会被系统直接杀掉。

小米 / Redmi / HyperOS 还需要（设置页有「MIUI 自启动」按钮直接跳转）：

- 手机管家 → 应用管理 → 权限 → **自启动** → 允许；
- 手机管家 → 应用管理 → 额度哨兵 → **省电策略** → 无限制；
- 最近任务卡片**下拉锁定**（加锁），避免一键清理时被杀；
- 设置 → 应用设置 → 应用管理 → 额度哨兵 → 通知 → 允许。

> 说明：任何 App 都无法 100% 保证不被系统杀。这里的组合（前台服务 + 常驻通知 + 电池白名单 +
> 开机自启 + AlarmManager 兜底 + 划掉任务后自动重启）已经是免 Root 下最稳的方案。
> 如果手机重启，服务会自动恢复；如果你在系统设置里“强行停止”，需要重新打开 App。

## 五、计划与额度

### 3 种计划模式（计划页）

| 模式 | 行为 | 适合 |
|---|---|---|
| 跟随额度窗口 | 在该账号额度窗口重置时自动发一条，把新窗口续上（默认） | 想尽量不浪费、也不多发的用户 |
| 固定间隔 | 每隔 N 分钟发一条（30–720 分钟） | 想让发送时间完全可控 |
| 每天定时 | 每天固定时间发一条 | 固定时段使用的人 |

每条计划可以单独开关；关闭某家计划后，这家不再自动发送（但仍可手动“立即续命”）。

### 额度是怎么算的

- **官方**：Claude / ChatGPT 能读到官方额度时，环形进度显示**官方已用比例**和官方重置时间，来源徽标为「官方」；
- **本地估算**：读不到官方额度时（常见于 Gemini），用本地滚动窗口估算：
  窗口小时数默认 **5 小时**，窗口内每成功发送一条计一次，条数上限默认 Claude 45 / ChatGPT 80 / Gemini 100，
  可在设置里改。来源徽标为「本地估算」；
- 官方数据重置时刻已过、但还没刷新成功时，徽标显示「待刷新」，不会拿旧百分比误导你；
- 额度卡片上的「手动重置额度窗口」可以把本地计数清零并重新开始计时（不会影响服务端真实额度）。

### 立即操作

- 首页每张卡片：**立即续命**（马上发一条）、**刷新额度**（马上拉一次官方数据）；
- 通知栏按钮：立即续命 / 刷新额度 / 暂停 2 小时；
- 首页时间线可查看最近 200 条记录。

## 六、自动更新

App 会从本项目的 GitHub Release 检查新版本：

- **自动**：每次冷启动时检查一次（6 小时内不重复）；发现新版本会弹出更新说明；
- **手动**：设置 → 维护与关于 → 检查更新；
- 点「下载并安装」后，如果系统提示“不允许安装未知应用”，在弹出的设置里允许本 App 安装应用，再回来重试；
- 更新是覆盖安装，**已连接的账号、代理和计划都会保留**；不会自动卸载旧版本；
- 如果你的网络访问 GitHub 不稳定，也可以到 [Releases 页面](https://github.com/DeepShawn/autoreset/releases) 手动下载 APK 安装。

## 六点五、Claude OAuth 令牌（可选，只影响额度显示）

如果不想依赖网页额度接口，可以把 Claude Code 的 OAuth 令牌导进来：

1. 在电脑上登录过 Claude Code 后，打开 `~/.claude/.credentials.json`，复制其中的 `accessToken`（`sk-ant-oat01-…`）；
2. App → 设置 → 账号连接 → Claude → 粘贴到「Claude Code OAuth 令牌」，保存并测试连接；
3. 之后 Claude 卡片的额度会走官方 `oauth/usage` 接口，显示 5 小时和 7 天两个窗口；
4. 注意：OAuth 令牌有效期约 8 小时，过期后重新复制；**令牌不能代替 Cookie 发消息**，保活发送仍需要上面的 `sessionKey` Cookie。

## 七、常见问题

**连不上 / 一直超时**：先确认代理开着且地址端口正确（设置 → 网络）；再点「测试连接」看具体报错。

**提示 Cookie 失效 / 风控**：浏览器重新登录对应服务，重新复制 Cookie；如果浏览器里也弹人机验证，先在浏览器完成验证。

**ChatGPT 发送成功但额度不更新**：ChatGPT 的额度接口经常变动，App 会回退到本地估算；不影响保活发送。

**额度显示 0% / 100%**：官方接口字段变了或窗口刚重置，点「刷新额度」；仍不对就看徽标是不是「待刷新」。

**划掉 App 后不运行了**：按第 4 节检查四项授权 + MIUI 自启动 + 最近任务加锁；部分系统（如某些 ColorOS/OriginOS）还需要允许“后台弹出界面”。

**Chrome 授权后没反应 / 读不到授权码**：确认点的是「Chrome 授权登录」、手机装有 Chrome；Claude 必须在授权完成页复制授权码再切回 App（剪贴板隐私限制时可点面板里的「点此读取」）；ChatGPT 若提示 1455 端口被占用，关掉占用端口的程序后重试。

**OAuth 令牌过期**：Claude 的 access token 约 8 小时有效，过期后重新点一次「Chrome 授权登录」即可。

**通知不显示**：设置 → 通知 → 允许；检查是否开了“静默通知/折叠通知”，常驻通知被折叠属于正常现象。

**耗电**：默认 4.5 小时才发一次、平时只做本地倒计时，正常待机耗电极低；如果把“自动刷新额度”调到 5 分钟，网络请求会明显增多，建议保持 15 分钟以上。

## 七、隐私

- 账号凭据（Cookie / token）只保存在 App 私有目录（`/data/data/com.aicode.quotasentry/`），不加密但也不出设备；
- App 不申请读取相册 / 通讯录 / 定位 / 短信权限，不包含任何广告或统计 SDK；
- 卸载 App 会同时清除所有凭据；
- 本项目为个人自用工具，与 Anthropic / OpenAI / Google 没有任何关联。
